# Dhaval Patel — Developer Portfolio

A responsive personal developer portfolio inspired by modern dark, editorial developer portfolio designs. Built with plain HTML, CSS, and JavaScript so it can be opened and edited easily in VS Code.

## Run in VS Code

1. Extract `dhaval-portfolio.zip`.
2. Open the `dhaval-portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser. Recommended: install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.
4. Edit `index.html` to personalize content and `styles.css` to adjust the design.

No npm install or build step is required. Google Fonts are loaded from the internet; system fallbacks are included.

## Before publishing

- Add your preferred public email address to the contact section and change the `mailto:` link in `index.html`.
- Add your GitHub and LinkedIn URLs when ready.
- Add GitHub repository/live demo links for projects you want to publish.
- Review every project description and stack to ensure it reflects the version you actually built.
- Add a résumé PDF to the project and link it from the hero if you want a download button.
- The included download button uses `assets/Dhaval_Patel_Resume.pdf`; keep this filename and path unchanged when publishing.

## Included

- Responsive navigation with mobile menu
- Hero section and code-card visual
- About, skills, projects, education, and contact sections
- CSS project mockups (no stock images needed)
- Subtle reveal animations and reduced-motion support
- Clipboard interaction for a contact-message template
